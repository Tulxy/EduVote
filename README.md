# 🎓 EduVote

EduVote je webová aplikace určená pro sběr, sdílení a hodnocení projektových nápadů ve školním prostředí. Umožňuje žákům navrhovat vylepšení školy a ostatním uživatelům o těchto návrzích hlasovat.

---

## 🚀 Funkce

* 📝 **Přidání návrhu**

  * Jednoduchý formulář pro odeslání nápadu
  * Název + popis návrhu

* 👍 **Hlasování**

  * Uživatelé mohou lajkovat návrhy
  * Zobrazení počtu hlasů

* 🛠 **Administrátorské rozhraní**

  * Schvalování nebo zamítání návrhů
  * Správa obsahu

* 📊 **Stavy návrhů**

  * `Navrženo`
  * `Schváleno`
  * `Zamítnuto`

---

## 🧰 Technologie

* Frontend: HTML, CSS, JavaScript
* Backend: PHP / Node.js
* Databáze: MySQL / Firebase
* (volitelně) Framework: React / Angular
